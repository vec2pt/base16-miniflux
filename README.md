# base16-miniflux

[Tinted theming](https://github.com/tinted-theming/home) template[^1] for [Miniflux](https://miniflux.app/) feed reader.

## Installation (Manual)

1. Copy the contents of the CSS file of the selected theme (e.g., `base16-default-dark.css`).
2. Go to Settings -> Application Settings (label frame) -> Custom CSS in Miniflux.
3. Paste the CSS into the text box.
4. Click Update button at the end of the Application Settings (label frame).

[^1]: Template based on [Catppuccin](https://github.com/catppuccin/miniflux) theme.
